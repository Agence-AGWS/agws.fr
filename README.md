# AGWS - Architecture Numérique

Site vitrine de la société **AGWS**
Développement Web, Applications Mobiles & Infrastructure Cloud.

🌐 **URL Production** : [https://agws.fr](https://agws.fr)

## Stack Technique
*   **Framework** : Astro (Static Site Generator)
*   **UI** : React + Tailwind CSS + Framer Motion

## Développement Local

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```
